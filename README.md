# Калькулятор стоимости сайта

Пет-проект на чистом JavaScript. Представляет собой калькулятор для подсчета примерной стоимости разработки веб-сайта в зависимости от выбранных услуг, количества страниц и срочности.

**Демо:** [https://xtz403.github.io/web-calculator/](https://xtz403.github.io/web-calculator/)

## Стек
* HTML5
* CSS3 (Flexbox, CSS-переменные)
* JavaScript (ES6+)

## Реализованный функционал
* Список услуг генерируется динамически из JS-массива (легко добавлять новые).
* Пересчет итоговой стоимости при клике на чекбоксы, движении ползунка или выборе срочности.
* Плавная анимация изменения цены с использованием `requestAnimationFrame`.
* Адаптивная верстка (карточка калькулятора подстраивается под экраны телефонов).

## Запуск
Скачать репозиторий и открыть файл `index.html` в браузере.
